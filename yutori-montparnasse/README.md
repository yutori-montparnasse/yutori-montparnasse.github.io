# ゆとりもんパルナス WEBサイト初案

HTML・CSS・JavaScriptで作成した静的サイトです。インストールやビルドは不要です。
ZIPを展開し、index.htmlをブラウザで開くと確認できます。
GitHub Pagesではindex.htmlと同じ階層にstyle.css、script.js、assetsを配置します。
現在は名称・紹介文・告知内容を確認するための初案で、公開作業は行っていません。

## ファイル

- index.html：紹介文、企画、メンバー、過去の活動
- style.css：色、文字、配置、スマートフォン表示
- script.js：スマートフォンのメニュー開閉
- assets/icon.jpg：ご提供の正方形アイコン
- assets/header.png：ご提供の新しいヘッダー（原画像）

## 長期運営

この1ページを継続して使用します。毎年別のサイトを作る必要はありません。
収録前は最新企画を変更し、公開後は動画リンクを追加します。
翌年の企画に切り替えるときに、前の動画をアーカイブへ追加します。
活動間隔が長い時期は、最新動画を案内する状態で維持できます。
告知できる内容がないときは、最新企画欄を非表示にする方法もあります。

## 更新箇所

index.htmlのid="latest"が最新企画、id="archive"がアーカイブです。
動画URLや公開日が確定してから、該当箇所にリンクや日付を追加してください。
現段階では未確認のSNSリンク、メンバーの個人プロフィールは掲載していません。
顔写真の加工、切り抜き、AIによる描き替えは行っていません。
モバイル向けアイコン、デスクトップ向けヘッダーを画面幅に応じて表示します。

## 確認状況

HTML内の画像・CSS・JSの参照先、ページ内リンクを確認済みです。
JavaScriptの構文とメニューの開閉・画面幅変更・Escapeキー動作を確認済みです。
ブラウザ画面での見た目と実機操作は未確認です。

## 初めて編集するとき

1. ZIPを展開し、フォルダを複製してバックアップを残します。
2. index.htmlをテキストエディタで開きます。
3. 「最新企画」「グループ紹介」などのコメントを検索します。
4. タグに挟まれた日本語を変更して保存します。
5. index.htmlをブラウザで開き直して確認します。

### 文章の変更例

```html
<span class="pill">
  企画準備中
</span>
```

「企画準備中」の部分を「公開しました」などに書き換えます。
<span ...> や </span> は残してください。
HTMLファイルでの改行は画面上の改行とは異なります。
画面上でも改行したい場所には <br> を入れます。
段落を分ける場合は <p> ... </p> を使います。

### 動画リンクの追加例

次のコードの URL と文章を、自分の内容に置き換えます。
これは書き方の例です。実際のURLが確定してから使ってください。

```html
<p>
  <a href="ここに確定した動画のURLを入れる">
    動画を見る
  </a>
</p>
```

### 画像の変更

assetsフォルダの画像を同名で差し替えるか、index.htmlの
src="assets/header.png" などを新しいファイル名に変更します。
大文字・小文字と拡張子も合わせてください。

### 色とサイズの変更

style.css の最初に基本色があります。
--paper は本文の背景色、--ink は基本の文字色です。
font-size は文字サイズ、padding は内側の余白、gap は項目間の間隔です。
スマートフォン用の設定は、コメント「スマートフォン用」で探せます。
同じ項目が複数ある場合は、後に書かれた設定が優先されることがあります。

文章・画像・リンクはHTML、見た目はCSS、メニューの動作はJavaScriptに分かれています。
普段の更新は、基本的にindex.htmlの編集だけで行えます。
